# Onboarding

Begin with the [Knowledgebase](../../KNOWLEDGEBASE.md) and the relevant [ADRs](../../DECISIONS.md), then use the README for the local Nuxt commands. Treat source, configuration, and executable checks as authoritative for current behavior.

Install and run using [package.json](../../package.json). Before changing a feature, identify its route, page, component, composable, data boundary, and test from the Knowledgebase's reading guidance. Keep the change scoped and run the smallest relevant checks.

Document lasting changes to application structure or development practice in the Knowledgebase; record architectural decisions in the ADRs rather than in temporary notes.

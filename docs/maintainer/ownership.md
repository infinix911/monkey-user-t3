# Ownership and sources of truth

The live application and its executable checks are authoritative. The [Knowledgebase](../../KNOWLEDGEBASE.md) provides the maintained architecture and feature map, while [ADRs](../../DECISIONS.md) hold permanent rationale. The [README](../../README.md) is the basic environment and runtime guide.

Keep ownership aligned with the repository's documented layers and conventions. When documentation disagrees with current code, verify the active route or entry point, then follow the source and tests. Update the Knowledgebase for durable map changes and add or supersede an ADR for a permanent technical decision.
